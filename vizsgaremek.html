Egy felhasználónak több rendelése lehet: felhasznalok 1 → N rendelesek
Egy rendelésben több tétel lehet: rendelesek 1 → N rendeles_tetelek
Egy terméket sokan rendelhetnek: termekek 1 → N rendeles_tetelek

Példa lekérdezés: a legnépszerűbb termékek

SELECT t.nev, SUM(rt.darab) AS eladva
FROM rendeles_tetelek rt
JOIN termekek t ON t.id = rt.termek_id
GROUP BY t.nev
ORDER BY eladva DESC
LIMIT 3;

A REST API végpontjai

Ezeken a címeken keresztül kér adatot a weboldal a szervertől. A GET lekér, a POST létrehoz, a PATCH módosít, a DELETE töröl. Az admin végpontokat csak bejelentkezett büfés használhatja.

GET/api/termekekAz összes elérhető termék listája
GET/api/termekek/{id}Egy termék adatai
POST/api/bejelentkezesBelépés e-maillel és jelszóval, a válasz egy token
POST/api/rendelesekÚj rendelés leadása
GET/api/rendelesekadminA mai rendelések listája
PATCH/api/rendelesek/{id}adminA rendelés állapotának módosítása
POST/api/termekekadminÚj termék felvétele
DELETE/api/termekek/{id}adminTermék törlése
